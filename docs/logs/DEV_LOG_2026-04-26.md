robot collapses to one side instead of transferring weight and stepping.

## Work done

### 1 — Enabled ENABLE_WALK, disabled ENABLE_SINGLE_LEG_BALANCE

`config.h`:
```c
#define ENABLE_WALK                 1
#define ENABLE_SINGLE_LEG_BALANCE   0
```

### 2 — Fixed latent preprocessor bug in all experiment files

**Symptom:** Linker error `undefined reference to 'task_walk(void*)'` when switching active mode.

**Root cause:** All `exp_*.cpp` files had their `#if ENABLE_*` guard placed before any `#include`. The preprocessor saw `ENABLE_WALK` as undefined (= 0) and compiled each file to an empty object. `main.cpp` (which includes `config.h` first) correctly saw `ENABLE_WALK=1` and called `task_walk`, but the linker found no definition.

**Fix:** Added `#include "../../include/config.h"` immediately before each `#if ENABLE_*` guard in:
- `exp_walk.cpp`
- `exp_slb.cpp`
- `exp_gait.cpp`
- `exp_balance.cpp`

### 3 — Weight transfer too weak: robot falls to float leg

**Symptom:** Robot collapses to the leg that should be floating instead of standing on the stance leg.

**Root cause:** `WALK_SHIFT_ROLL_DEG = 7°` was barely above the geometric minimum (~6.6°). With servo compliance and ground friction, this did not transfer enough weight to unload the float foot before SWING fired.

**Fix:**
```c
#define WALK_SHIFT_ROLL_DEG        14.0f   // was 7.0
#define WALK_SHIFT_THRESHOLD_DEG    8.0f   // was 4.0
#define WALK_SHIFT_STABLE_CYCLES   20      // was 10 (~200 ms dwell)
```

### 4 — Hip roll and ankle roll physically inverted in walk controller

**Symptom:** SHIFT_RIGHT shifted CoM to the LEFT foot instead of the right. Ankle on the right foot rolled the wrong direction.

**Root cause:** All hip_roll and ankle_roll signs in `walk.cpp`'s `shift_target()` and `swing_output()` were physically inverted — the code produced a leftward lean when a rightward lean was commanded, and vice versa.

**Fix:** Negated all hip_roll and ankle_roll assignments in both functions:

`shift_target()` SHIFT_RIGHT:
```cpp
// Before
t.left.hip_roll = +sr;  t.right.hip_roll = -sr;
t.left.ankle_roll = -sr;  t.right.ankle_roll = +sr;

// After
t.left.hip_roll = -sr;  t.right.hip_roll = +sr;
t.left.ankle_roll = +sr;  t.right.ankle_roll = -sr;
```

SHIFT_LEFT and both swing phases updated symmetrically. `target_roll_rad()` and `imu_gate()` required no changes — their sign conventions were already consistent.
